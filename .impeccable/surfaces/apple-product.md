# 两站产品官网展示约定

用户明确选择苹果产品官网式体验，保留绿色标识、粒子字标与项目星球。采用代码实现，不使用苹果资产或概念图替代真实项目素材。

## 首屏与访问路径

首屏是独立站点字标与可点击项目星球组成的黑色舞台。弱化轨道和网格；散落星星直接用 1500ms 聚合，随后星球和轨道用同一活跃时钟在 320ms 内淡入，随后在真实字形内持续流动。约三分之一字形粒子参与局部流动，桌面幅度 4px、手机 1px，采样字形的安全半径限制位移，保留清晰字边。桌面指针在字标 120px 半径内触发平滑局部响应，最多四个短轨迹在 600ms 内衰减；链接和动画按钮不触发指针响应。桌面入口及指针交互绘制上限 60fps，桌面静置上限 30fps，宽度 <1024px 全程上限 10fps。字标是品牌展示，后续章节立即说明产品、选型与实际用途。

桌面宽度 ≥1024px 时，星球视觉直径为 80px；1024–1279px 或高度 <720px 使用 72px；高度 ≤500px 使用 64px。凸显只放大内部视觉层至 1.35 倍，极矮屏为 1.25 倍，原生链接命中范围按最大凸显尺寸保持稳定。清晰描边表达选中状态。桌面星球沿椭圆路径等距分布，避免短屏两侧拥挤。桌面常态显示小号项目名，上半轨道的名称在星球上方、下半轨道在下方，名称随轨道运行，位于链接外且不拦截点击。选中时在字标下方显示项目名与 catalog 现有双语用途，高度 ≤700px 改为紧凑横排；可选用途缺失时仅显示名称。保留官方链接、真实 Logo、统计属性、可见焦点与稳定的无障碍用途说明。

独立星球控制器在字标聚合完成且首屏可见 3 秒后选中第一个项目，保持 4 秒，再间隔 3 秒按现有十个星球顺序轮换；每次只凸显一个，凸显期间暂停整个轨道，粒子仍流动。键盘聚焦优先于悬停，悬停优先于自动选择；结束交互后等待 3 秒继续公平轮换，手动选中不改变自动顺序。首屏右下角统一控制全部首屏动画，按钮至少 44px，双语操作名称为“暂停首屏动画／继续首屏动画”与“Pause hero animation／Resume hero animation”，按下状态及暂停／播放图标同步。手机显示 44px 图标按钮，保留完整无障碍名称。手动暂停冻结粒子相位和轨道、保留当前自动选择与重连后的暂停状态；继续时清除自动选择并重新计时。轮换不移动键盘焦点、不自动播报。

星球控制器订阅共享首屏阶段，ready 前隐藏星球、名称、轨道与说明，链接 inert 且不进入辅助技术树；停止轨道与自动计时。暂停按钮在加载期间独立可用。离屏、后台、减少动态效果或离开桌面断点时清除自动选择与计时，恢复后从完整 3 秒延迟开始，不补跑。粒子聚合与星球淡入共享活跃时钟及调度器；暂停、离屏和后台冻结全部相位，重连不重播。减少动画、WebGL 失败、字体失败／超时和无 JS 时，中央只显示静态星空，下方原生项目入口仍可用。减少动画解除后成功绘制才恢复保存相位。手机／平板保留 44px／52px 星球尺寸，不显示自动聚焦或说明，不引入动画依赖。

首页顺序：项目导航、定位与选型、工程/组件/数据和宽幅交互演示、独立样式章节、Taro 迁移、Runtime 选型、uni-app 生态、工具链和真实发布；商业站随后说明开源站、服务、合作流程、规划、联系与自愿赞助，开源站以贡献入口结束。

## 视觉承诺

中性白/浅灰和黑/深灰；绿色用于主操作与状态。Geist 负责标题和正文，中文使用系统字体。36–64px 章节标题，40–80px 页面标题，24–32px 目录项目标题，代码和真实数据使用等宽字体。1240px 内容宽度，桌面章节 80–112px 留白，手机 56–64px。宽幅演示与真实截图承担展示，信息行、安静色块与长文布局交替，不把所有章节卡片化。

44px 触控目标；圆形主按钮；媒体/浮层 20px 圆角。正文始终可见，短距离入场增强不隐藏内容。保留双语、主题、路由、十一个项目、价格与基金规则，应用不相互依赖。

## 验收范围

截图清单见 .impeccable/review/capture.json：两站首页 320/390/1280/1440px，目录、weapp-vite 详情、隐私及商业报价/赞助 390/1440px，中英文、浅深主题。配合 E2E 验证无 JS、减少动态效果、焦点、筛选、演示、复制、联系方式、图表及 Pages 子路径。首屏脚本体积与改造前基线比较，不以截图宣称生产性能。

首屏增强另验 1024/1920px 桌面和短屏；检查星球、名称和用途不裁切、不与字标重叠、不产生横向溢出。行为覆盖真实字形持续运动、60/30/10fps 预算与指针衰减、单星选择、完整轮换、聚焦／悬停优先、统一暂停继续、离屏／后台相位恢复、动态修改减少动画偏好、断点切换、组件重连及 WebGL 失败。粒子运动证据限定字形区域，并核对实际 GL 参数，不以背景尘埃运动代替字标验收。

## 星空开场与首页字体

首个 HTML 画面呈现低亮度、固定种子的内联 SVG 星场，中央不显示小程序 Logo 或 HTML 文字，站名 H1 仅供辅助技术。SSR 与 WebGL 共用背景星位、尺寸和亮度；字形粒子从零亮度随收束渐亮，首个有效帧才交接。舞台中立锚点负责中心，不依赖 Logo 路径或元素尺寸。桌面预留 64px 底部控制区域，星球说明仅在 ready 后显示；高度≤700px的短屏用底部紧凑布局。

中央字标专用 Syne 700、-0.02em 字距，其余界面保持 Geist。@fontsource/syne 5.3.0 Latin WOFF2 自托管、仅首页预加载并保留 OFL。真实字体等待最多 3 秒，失败或超时本次挂载保持星空，迟到字体不切换。异步初始化有代次保护，等待不累计活跃时间。真实墨迹居中和缩放，完整保留圆点、下伸部及与星球的 16px 间距。舞台明确高度，独立轨道层以半径长度定义 motion-path 中心，避免浏览器零尺寸百分比参考框。
