# 双应用拆分验收

本文件记录拆分基线；后续设计改造与最新验证结果见[产品官网设计验收](apple-design-validation.md)。

## 已验证

- pnpm install --frozen-lockfile --ignore-scripts：锁文件通过依赖策略校验。
- pnpm check：两应用和共享包的 lint、样式、类型、单元测试全部通过；两个 Astro 应用均为 0 errors、0 warnings、0 hints。
- 138 项单元与边界测试通过：边界 6、项目资料包 14、UI 包 9、商业站 66、开源站 43。
- pnpm build：两站独立产物通过页面、SEO、内部链接及开源资源边界验证。
- 商业站 Playwright：348 passed、30 skipped；开源站 Playwright：316 passed、30 skipped。跳过项包括设备专属矩阵、非本站功能和需单独启用的真实统计协议测试。
- 单应用隔离构建：分别创建只包含一个应用、共享目录和根配置的临时目录，复用已安装依赖，按应用 build 命令的步骤执行资源准备、Astro、OG、发现资源、Pages 路径改写和最终产物验证；两站均通过。临时目录构建无须另一应用源码。
- CI YAML 解析通过；两站使用不同验证任务名称、产物、并发组和部署权限。共享路径触发两站，各应用路径仅触发自身工作流。
- git diff --check 通过。
