# 星空直接聚合成字标验证

2026-10-10，weapp.dev 与 weapp.js.org 同步替换首屏入场流程。当前约定见根目录 [首屏共享规范](../DESIGN.md#particle-wordmark-and-project-planets)；本记录取代此前 Logo 开场方案的当前行为约定，原始证据位于 `/tmp/weapp-star-intro-20261010/`。

## 视觉顺序与降级

首个 HTML 画面只显示低亮度星空，没有中央小程序 Logo、可见 HTML 字标、项目星球、名称或椭圆轨道。品牌 H1 仍可访问，但文本在视觉上裁切。字体与 WebGL 就绪后，散落星星直接用 1500ms 聚合成各站的 Syne 700 品牌文字，不再停留 700ms 或采样 Logo 轮廓。字标完成后，星球、名称及轨道用 320ms 淡入；桌面自动凸显从字标完成开始等待 3 秒。

SSR 和 WebGL 使用同一固定种子的标准化星位、CSS 尺寸与低亮度。静态 SVG 输出 400 个圆点，宽度不足 720px 时仅显示前 160 个，与渲染器背景预算一致。字形粒子仍使用 900／2400 的预算，从分散源点以零亮度开始，随着聚合渐亮；首个有效绘制帧才隐藏静态星场。中立舞台锚点负责中心，原先的 Logo 元素不参与布局或渲染。Syne、字距 -0.02em、真实墨迹拟合、字内流动和指针涟漪继续沿用。

无 JavaScript、字体加载失败或 3 秒超时、WebGL 失败、减少动态效果时，中央仅保留静态星空。首屏项目星球保持隐藏且 inert，不可聚焦或点击；下方原生项目栏和正文入口继续可用。字体晚到不会切换本次挂载的画面。

## 状态与生命周期

共享作用域状态为 stars／assembling／ready，由有效 WebGL 绘制更新，并通过作用域事件通知星球控制器。ready 前星球链接 inert、从辅助技术树隐藏，停止轨道及轮换计时，清空手动和自动项目说明。暂停按钮在脚本就绪后独立工作，字体等待期间也能暂停。

聚合与星球淡入共用已有活跃时钟和绘制调度器，没有新动画依赖或第二套 RAF。桌面入场、淡入和指针交互最多 60fps，空闲最多 30fps，手机／平板全阶段最多 10fps。手动暂停、离屏和后台冻结聚合、淡入与相位；恢复不累计隐藏时间。减少动画立即回到静态星空，解除后成功绘制才恢复保存的相位。断开取消初始化并释放资源，重连使用代次保护和保存相位。

尺寸变化能立即静态重绘时，保留当前 ready 阶段、焦点、悬停和暂停状态；只有无法重绘或真实绘制失败才回到 stars。避免以暂时的阶段切换清空项目焦点或重新启动自动延时。

## CI 尺寸断言修正

首次开源站 CI 的 416 项通过、42 项跳过，商业站 460 项通过、42 项跳过；两站均只有两个桌面缩放用例在恢复 1440px 宽度时失败。测试把画布宽度等同于窗口宽度，而渲染器的尺寸契约是实际舞台 `clientWidth` 乘以 DPR。开源站中英文失败 trace 确认：Linux Chromium 的 DPR 为 1，1440px 窗口中画布 CSS 宽度与绘制缓冲均为 1425px，1280px 时均为 1265px；既有 `scrollbar-gutter: stable` 预留了 15px，ResizeObserver 已正确完成。双站用例统一改为要求绘制缓冲宽度发生变化，并精确匹配实际舞台尺寸。焦点、项目说明、ready 和手动暂停断言全部保留，没有修改渲染器或放宽阈值。

修正后的双站中英文桌面缩放定向回归共 4 项通过，两站 TypeScript 和测试文件 ESLint 检查通过。原始失败日志为 `ci-open-source-failed.log` 与 `ci-commercial-failed.log`，开源站截图和 trace 位于 `ci-open-source-evidence/`，定向回归记录为 `resize-open-source.log` 与 `resize-web.log`。
