# 2026-10-27 Hero 分层入场与景深

## 变化与边界

两站复用 `packages/site-ui` 的粒子 Logo、字标和项目单椭圆轨道。参考 Koimsurai 的分层入场与远近星场，通过现有 WebGL2 pass、活跃时钟与帧预算实现，不新增动画依赖、canvas 或调度循环。公共组件 props、项目导航、双语内容与静态降级保持原有契约。

Logo 停留 700ms、字标形变 1500ms 后进入 ready。原 320ms 展示窗口分为重叠层次：

| 层                    | 相对 ready 的活跃时间 |
| --------------------- | --------------------- |
| CSS 轨道与 WebGL 星尘 | 0–180ms               |
| 项目星球本体          | 60–260ms              |
| 项目名称与说明        | 160–320ms             |

所有层在 2520ms 完成入场，自动项目凸显仍从 ready 起等待完整 3 秒。ready 阶段键盘聚焦的星球始终可见。暂停、离屏和后台冻结全部层次，重连继续保存相位，重播恢复同一入场。

## 背景渲染与生命周期

现有背景星按固定种子分为远近两层，总数及 SSR 样本不变。近层漂移周期 45–75 秒，远层 90–150 秒；闪烁继续使用 6–12 秒错相周期。精细鼠标在宽度至少 1024px 时驱动背景视差，远层径向上限 2px、近层 6px，约 250ms 活跃时间内收敛 95%。Logo、字标与轨道保持锚定。触屏、窄屏、项目链接和控制按钮不驱动视差；指针离开后平滑回中。

`hero-background-motion.ts` 管理纯输入平滑和可恢复 snapshot，`hero-starfield-renderer.ts` 管理背景 shader 片段与已有样本的 buffer 打包。主 pass 增加一个 float attribute/buffer，合计 15 个 attribute，低于 WebGL2 至少 16 个的要求。漂移与视差共同受星点边缘空间预算限制；现有资源释放路径处理新增 buffer 与媒体查询监听。

暂停和重连保留当前位移，重播清空位移与目标。SSR 与有效 GL 首帧的位置、尺寸、亮度保持一致。桌面入场及交互最多 60fps、空闲 30fps，宽度不足 1024px 全阶段 10fps；无 JS、减少动画、字体失败或超时、WebGL 失败保留静态 Logo 与星空。

活跃时钟与最后成功绘制的时间分别保存。暂停重连和暂停后的尺寸重绘使用已绘制时间，还原冻结画面；恢复运行继续使用活跃时钟，保留暂停前尚未绘制的时间差。视差的零时间恢复也不触发近零吸附，避免静态重画改变保存的位移。

脚本足迹以 `4e2680a` 为基线，使用同一 esbuild 0.28.2、ES2022、ESM、minify 与入口调用，对粒子和星球运行时生成独立合并 bundle。压缩前为 51,957 → 54,142 B，gzip 为 23,869 → 24,740 B（增加 871 B），Brotli 为 21,413 → 22,134 B（增加 721 B）。这是隔离脚本边界的比较，不是 Astro 生产 chunk 测量；不包含 CSS、字体、SSR SVG 或其他页面脚本。命令、参数、来源哈希和产物记录在 `.cache/dependency-upgrade-2026-10-27/hero-footprint.mjs` 与 `hero-footprint.json`。

浏览器回归找出了两类需要处理的问题。暂停落在两次绘制之间时，逻辑时钟比最后画面多出约 5ms，原先重连会让冻结中的入场前进；本轮通过保存已绘制时间修复，新增纯时钟测试和实际 DOM 重连断言。另一类来自测试取样：小星点的亚像素栅格覆盖会使全场亮度质心失真，改用真实像素的局部平移配准；旧冷缓存用例则改读 computed opacity，并在 10fps 手机帧预算下跨过新增的 60ms 本体延迟。两站补跑和完整回归均已收敛，未降低位移或入场的验收门槛。

上述 fps 结果验证调度上限和冻结行为，不等同于实体设备的持续帧率或 GPU 耗时测试。本轮视觉结果来自实际生产静态产物，动态入场和视差另由浏览器时钟、DOM 与 framebuffer 回归验证。

截图检查复用一个 headless browser/context/page，32 个场景完成后全部关闭。HMR 同样复用一个工作页面，临时源码按 SHA256 恢复，两个开发端口关闭；完整 E2E 的静态服务也已退出。任务没有保留临时浏览器页面或运行中的服务。
