# 首页与应用边界

商业首页位于 apps/web，保留原有粒子字标、项目星球与项目导航；随后依次呈现定位与选型、项目展示与演示、工具链、真实发布、独立开源站介绍、当前服务、合作流程、规划中能力、联系方式和自愿赞助。九个项目的目录和详情保留完整资料，同时补充实施范围及同语种开源详情入口。

开源首页位于 apps/open-source，保留项目星图、生态分区、演示、发布和贡献入口，不包含商业服务、赞助或主域服务导流。两应用独立维护页面编排、布局、导航、文案和 SEO。

packages/project-catalog 提供九个项目的事实、素材和指标。packages/site-ui 提供中立的粒子、星球、项目行、演示及配套样式，接收显式的字标、文案、链接与数据；它不读取应用目录或站点配置。应用只通过公共包导出使用共享代码。应用 CSS 从自身安装的 UI 包扫描 Tailwind 类名，不扫描另一个应用。

商业服务映射只由 apps/web 的 services.ts 维护，不能从项目成熟度或目录成员关系推导。两应用不通过部署变量改变身份。详见[维护手册](../maintenance.md)；docs/plans 中的单应用方案为历史记录。
