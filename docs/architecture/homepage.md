# 首页与应用边界

商业首页位于 apps/web，保留原有粒子字标、项目星球与项目导航；随后依次呈现定位与选型、项目展示与演示、工具链、真实发布、独立开源站介绍、当前服务、合作流程、规划中能力、联系方式和自愿赞助。十一个项目的目录和详情保留完整资料，同时补充实施范围及同语种开源详情入口。

开源首页位于 apps/open-source，保留项目星图、项目导航、定位与选型、生态分区、演示、工具链、发布和贡献入口，不包含商业服务、赞助或主域服务导流。两应用独立维护页面编排、布局、导航、文案和 SEO。

两站正文将工程、组件与数据（weapp-vite、Varo、weapp-sqlite）放在 #projects，随后以独立的 #styling 样式章节集中展示 weapp-tailwindcss、weapp-pandacss 与 weapp-stylex。样式章节使用共享的柔和背景 token，保留项目状态、事实证明、文档和详情入口；选型介绍可直接跳转到该章节，章节内可进入同语种的样式项目筛选目录。该展示分组由应用维护，不改变项目目录的生态归属或商业服务范围。交互演示的 tab 顺序独立于章节阅读顺序。

两站首屏展示目录中的十一个项目星球，weapp-sqlite 沿用排序 6，位于 Varo 之后，并使用官方独立图标。它按本站的保守分类展示为 Beta，推荐安装 @weapp-sqlite/weapp-vite；已验收平台为 Web 与真实微信开发者工具，微信真机仍待验证。数据演示展示官方异步查询与关闭连接的静态代码，注明 weappSqlite() 插件配置前提，页面不执行数据库。项目 ID 与详情路由独立于 npm 包名。

Vue Mini 与 Rezor 在 #runtime 合并为运行时选型章节，按项目目录中的 Framework 角色选取并按目录顺序排列。桌面并排展示，手机纵向排列；项目卡片标出 Vue 3 / React 和真实成熟度，分别链接官方资料及站内详情。旧的 #ecosystem-vue-mini 与 #ecosystem-rezor 锚点保留在各自卡片上。目录生态归属和星球导航继续独立维护。

## 共同视觉语言

两站采用已确认的苹果产品官网式展示语言：中性白/浅灰与黑/深灰、Geist 标题及正文、中文系统字体回退、大标题、宽裕章节留白、绿色主操作、胶囊按钮和真实项目演示。使用自有与项目真实素材，不使用苹果私有资产。视觉规范和实际 token 见根目录 [DESIGN.md](../../DESIGN.md)，应用职责见 [商业站设计约定](../../apps/web/DESIGN.md)与[开源站设计约定](../../apps/open-source/DESIGN.md)。

内容宽度上限为 1240px；桌面章节采用 80–112px 的纵向节奏，手机采用 56–64px。章节标题为 36–64px，通用页面标题为 40–80px。项目说明、宽幅演示、轻量信息行与安静色块交替，避免把所有内容装进卡片。主媒体、演示外框与浮层采用 20px 圆角，紧凑证据框与筛选器采用 12px；演示内部保留局部紧凑控件样式。

## 首屏与渐进增强

两站首屏遵循根目录 [首屏共享规范](../../DESIGN.md#particle-wordmark-and-project-planets)。SSR 输出小圆点组成的小程序 Logo、低亮度固定星场与视觉隐藏的品牌 H1；Logo 使用共享点源，宽度不足 720px 时 900 点，其余 2400 点，不输出实心轮廓。点表由 `node scripts/generate-hero-logo.mjs` 按固定种子离线生成，保留 7 viewBox px 的轮廓安全边距和至少 0.5px 的圆盘间距，`--check` 验证规范路径与产物一致；非重叠保证加法混合交接时不叠加源点亮度。真实 Syne 700 字体和有效 WebGL 首帧就绪后，同时交接 Logo 与星空；Logo 先停留 700ms，再用 1500ms 变形成各自字标。阶段状态 logo／assembling／ready 由共享作用域事件通知星球控制器；2200ms 进入 ready，之前星球和轨道不可见、链接 inert，之后在同一活跃时钟下以 320ms 淡入，2520ms 完成入场。桌面自动凸显从 ready 起等待 3 秒。背景完成聚合后仍有 6–12 秒错相闪烁（相对起始亮度 ±25%）与 45–75 秒缓慢漂移；球面使用固定方向光影、微弱项目色反射和保留 Logo 原色的独立不透明面，选中时只放大星球内部视觉并强调球面描边与反射，恒定冰白色轨道核心与光环不随选择改变。统一暂停、离屏、后台和重连延续相位；减少动画、字体失败或超时、WebGL 失败及无 JavaScript 时保留静态粒子 Logo 与星空，轨道链接继续隐藏且 inert，下方原生项目入口始终可用。字标维持 Syne 700、-0.02em、真实墨迹拟合和后续字内流动；绘制预算为桌面入场／交互 60fps、空闲 30fps，手机／平板全程 10fps。

轨道由 CSS 的恒定冰白色 1px 核心与约 8px 柔和晕光（手机约 6px），以及同一 WebGL canvas 内的可选星尘层组成。星尘使用固定种子和椭圆弧长等距位置，法向抖动不超过 2px；宽度 ≥1024px／640–1023px／<640px 的预算分别为 960／384／256 个点。配色复用已有翡翠、冰蓝、香槟与珍珠色，以珍珠色为主；各点位置锚定，只按 6–12 秒错相周期独立闪烁，亮度在起点 ±25% 内变化，整圈亮度与星球选中状态无关。可选层复用现有活跃时钟、ready 门禁、320ms reveal 与 60／30／10fps 调度，暂停、离屏、后台、重播和重连沿用原首屏生命周期，不增加调度循环。星尘独占的 program 与 VAO 随断开释放，初始化失败也释放已创建的资源；测试探针分别记录 program／VAO 数量，验证失败隔离和重连清理。仅星尘初始化失败时继续显示 CSS 核心并保持原粒子渲染器运行；无 JavaScript、减少动画、字体失败／超时与主 WebGL 失败仍使用静态 Logo 与星场降级。

正文默认可见，进入视口后的短距离位移动画只作增强，不以透明度或观察器状态阻塞阅读。保留键盘焦点、44px 共享按钮/图标控制目标、减少动态效果和减少透明度支持。两个应用均在没有有效保存值时默认深色，随后遵循各自站点 localStorage 中的 weapp-theme 明确选择；不改为系统主题或默认浅色。

## 共享与所有权

packages/project-catalog 提供十一个项目的事实、素材和指标。packages/site-ui 提供中立的粒子、星球、项目行、演示、基础视觉 token 及配套样式，接收显式的字标、文案、链接与数据；它不读取应用目录或站点配置。应用只通过公共包导出使用共享代码。应用 CSS 从自身安装的 UI 包扫描 Tailwind 类名，不扫描另一个应用。应用仍拥有自身布局、样式组合和本地交互。

商业服务映射只由 apps/web 的 services.ts 维护，不能从项目成熟度或目录成员关系推导。两应用不通过部署变量改变身份。开源站历史资助相关 URL 保持站内、同语种、noindex 静态跳转。详见[维护手册](../maintenance.md)；docs/plans 中的单应用方案为历史记录。

## 验证边界

视觉调整不改变十一个项目、真实维护者与指标、既有路由、价格、赞助和基金规则。验收覆盖两站中英文、浅深主题、320/390/1280/1440px 首页，以及目录、详情、隐私和商业报价/赞助页面；同时验证无 JavaScript、减少动态效果、键盘、筛选、演示、复制、联系方式、图表和 Pages 子路径。截图清单见 .impeccable/review/capture.json。首屏脚本与改造前基线比较；截图不作为生产性能证明。
