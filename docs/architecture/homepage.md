# 首页与应用边界

商业首页位于 apps/web，保留原有粒子字标、项目星球与项目导航；随后依次呈现定位与选型、项目展示与演示、工具链、真实发布、独立开源站介绍、当前服务、合作流程、规划中能力、联系方式和自愿赞助。十一个项目的目录和详情保留完整资料，同时补充实施范围及同语种开源详情入口。

开源首页位于 apps/open-source，保留项目星图、项目导航、定位与选型、生态分区、演示、工具链、发布和贡献入口，不包含商业服务、赞助或主域服务导流。两应用独立维护页面编排、布局、导航、文案和 SEO。

两站正文将工程、组件与数据（weapp-vite、Varo、weapp-sqlite）放在 #projects，随后以独立的 #styling 样式章节集中展示 weapp-tailwindcss、weapp-pandacss 与 weapp-stylex。样式章节使用共享的柔和背景 token，保留项目状态、事实证明、文档和详情入口；选型介绍可直接跳转到该章节，章节内可进入同语种的样式项目筛选目录。该展示分组由应用维护，不改变项目目录的生态归属或商业服务范围。交互演示的 tab 顺序独立于章节阅读顺序。

## 共同视觉语言

两站采用已确认的苹果产品官网式展示语言：中性白/浅灰与黑/深灰、Geist 标题及正文、中文系统字体回退、大标题、宽裕章节留白、绿色主操作、胶囊按钮和真实项目演示。使用自有与项目真实素材，不使用苹果私有资产。视觉规范和实际 token 见根目录 [DESIGN.md](../../DESIGN.md)，应用职责见 [商业站设计约定](../../apps/web/DESIGN.md)与[开源站设计约定](../../apps/open-source/DESIGN.md)。

内容宽度上限为 1240px；桌面章节采用 80–112px 的纵向节奏，手机采用 56–64px。章节标题为 36–64px，通用页面标题为 40–80px。项目说明、宽幅演示、轻量信息行与安静色块交替，避免把所有内容装进卡片。主媒体、演示外框与浮层采用 20px 圆角，紧凑证据框与筛选器采用 12px；演示内部保留局部紧凑控件样式。

## 首屏与渐进增强

两站首屏保持各自固定字标与可点击项目星球，使用近黑色舞台，减弱网格和轨道，不增加装饰光晕。粒子停留 700ms 后以 1500ms 聚合，聚合后最多每秒绘制 10 次；离屏及页面进入后台时暂停。减少动态效果与无 JavaScript 时显示静态字标。

正文默认可见，进入视口后的短距离位移动画只作增强，不以透明度或观察器状态阻塞阅读。保留键盘焦点、44px 共享按钮/图标控制目标、减少动态效果和减少透明度支持。两个应用均在没有有效保存值时默认深色，随后遵循各自站点 localStorage 中的 weapp-theme 明确选择；不改为系统主题或默认浅色。

## 共享与所有权

packages/project-catalog 提供十一个项目的事实、素材和指标。packages/site-ui 提供中立的粒子、星球、项目行、演示、基础视觉 token 及配套样式，接收显式的字标、文案、链接与数据；它不读取应用目录或站点配置。应用只通过公共包导出使用共享代码。应用 CSS 从自身安装的 UI 包扫描 Tailwind 类名，不扫描另一个应用。应用仍拥有自身布局、样式组合和本地交互。

商业服务映射只由 apps/web 的 services.ts 维护，不能从项目成熟度或目录成员关系推导。两应用不通过部署变量改变身份。开源站历史资助相关 URL 保持站内、同语种、noindex 静态跳转。详见[维护手册](../maintenance.md)；docs/plans 中的单应用方案为历史记录。

## 验证边界

视觉调整不改变十一个项目、真实维护者与指标、既有路由、价格、赞助和基金规则。验收覆盖两站中英文、浅深主题、320/390/1280/1440px 首页，以及目录、详情、隐私和商业报价/赞助页面；同时验证无 JavaScript、减少动态效果、键盘、筛选、演示、复制、联系方式、图表和 Pages 子路径。截图清单见 .impeccable/review/capture.json。首屏脚本与改造前基线比较；截图不作为生产性能证明。

本轮验证结果与证据见[设计验证记录](../apple-design-validation.md)。
