# 粒子小程序 Logo 与星系质感验证

2026-10-11，weapp.dev 与 weapp.js.org 同步恢复由独立星点组成的小程序 Logo 开场。本记录更新上一轮星空直接聚合方案；当前设计约定见根目录 [首屏共享规范](../DESIGN.md#particle-wordmark-and-project-planets)。原始验证证据位于 `/tmp/weapp-particle-logo-20261011/`。

## 视觉与实现

第一帧由 SSR 输出粒子 Logo 和低亮度星空，中央没有实心轮廓或可见 HTML 字标。字体及首个有效 WebGL 帧就绪后，Logo 按活跃时间停留 700ms，再用 1500ms 连续变形成各站 Syne 700 字标；2200ms 进入 ready，星球、名称和轨道在随后 320ms 内淡入，2520ms 完成。桌面自动凸显从 ready 起等待 3 秒。

规范小程序路径离线生成固定种子的 2400 点表，手机使用均匀分布的前 900 点。圆盘中心保留 7 viewBox px 轮廓安全区，圆盘间距至少 0.5px，避免 SVG 合并路径与 GL 加法混合在重叠源点处产生亮度跳升。SSR 仅用 18 个分组路径表达独立圆点，手机隐藏其中额外的 1500 点路径。源点位置、直径和亮度使用同份数据；生成器 `--check` 验证点表没有偏离规范路径。变形时源圆随点精灵连续缩放，避免较小目标尺寸裁掉圆边。

背景保留桌面 400／手机 160 点预算。6–12 秒错相闪烁将常态亮度变化限制在起始值 ±25%，45–75 秒漂移使用首帧归零的周期波形，桌面幅度 6–16px、手机／平板 2–6px，边缘安全距离进一步限制位移。少量亮星有柔和星芒。背景与字标共用已有时钟、一次绘制及单调度器；字标完成后背景仍同时移动和闪烁。

星球使用统一左上光源、柔和右下阴影及少量项目色反光。外缘减薄，独立不透明承载面有轻微球面明暗，真实 Logo 保持原色。椭圆后半较暗、前半较亮，桌面选中星球附近的短亮弧由实际链接中心与轨道中心计算；手机不显示这段弧。尺寸、稳定命中区域和放大比例沿用现有约定。

## 降级与生命周期

无 JavaScript、字体失败或 3 秒超时、字体晚到、WebGL 失败及减少动画时，显示静态粒子 Logo 与星空，首屏轨道链接保持隐藏且 inert；下方原生项目入口继续可用。品牌 H1 始终可访问。

字体等待不累计入场时间。手动暂停、离屏和后台冻结停留、变形、背景和星球淡入；恢复及重连延续保存相位，不补跑或重播。暂停期间缩放只允许一次静态重绘。动态开启减少动画立即回到静态 Logo，解除后按保存相位和暂停状态恢复。原有字内流动、指针涟漪、轮流凸显和统一暂停保留；没有新增运行时或动画依赖，公共 props 与 GlyphPoint 不变。
