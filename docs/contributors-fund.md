# 贡献者计划

公开规则以网站为准：

- 中文：https://weapp.dev/contributors/
- English：https://weapp.dev/en/contributors/
- 赞助入口：https://weapp.dev/pricing/#sponsor

## 资金三桶

已确认到账且未指定项目的开源赞助（个人档位与 Gold 企业合作），扣除支付手续费后按净额拆分：

| 比例 | 用途                                         |
| ---- | -------------------------------------------- |
| 60%  | 核心维护：维护者时间、测试、CI、域名和文档站 |
| 25%  | 贡献者基金：季度池 + 定向赏金                |
| 15%  | 周边开源：小程序生态相关上游                 |

当季基金不足 ¥500 时滚存。产品收入（未来的 Pro / Team / 实施）不进入本基金。核心维护者不从 25% 领取。

## 指定项目捐赠

如果想支持其他开源项目，请在捐赠时备注「捐给 XXX 项目」，也可以在捐赠后私信我，补充项目名称。名称容易混淆时，可附上项目仓库链接；忘记备注时，可后续私信补充项目名称和捐赠信息，便于核对。

指定项目的捐赠经我确认后按指定用途单独处理，不纳入上述 60%／25%／15% 默认分配。未指定项目的赞助沿用默认规则。公开致谢仍需身份确认、审核和授权，捐赠备注及私信内容不会自动公开。

## 覆盖仓库

- [weapp-vite](https://github.com/weapp-vite/weapp-vite)
- [weapp-tailwindcss](https://github.com/sonofmagic/weapp-tailwindcss)

- [weapp.dev](https://github.com/sonofmagic/weapp.dev)

Varo 不默认进入本计划。

## 账本

每季在 [sonofmagic/sponsors](https://github.com/sonofmagic/sponsors) 开一期公开 issue，列出到账净额、三桶、权重、领取人和滚存。
