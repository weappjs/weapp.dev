## 实现与资产

SSR 首帧直接显示内联小程序 Logo，品牌 H1 保持可访问，页面不先闪现可见的 HTML 字标。SSR Logo 与粒子起始轮廓共用 SVG 路径、实际尺寸和中心；只有成功绘制真实首帧后才交接到 Canvas。无 JavaScript、WebGL 失败和减少动态效果均保留静态 Logo，原生项目链接仍可使用。

粒子字标采用自托管 Syne Latin 700 WOFF2，字距为 `-0.02em`；正文和导航保留现有字体。字体来自 `@fontsource/syne` 5.3.0，文件为 14,072 bytes，并随构建保留 OFL 授权。每站仅中文 `/` 与英文 `/en/` 两条首页 HTML 路由启用字体预加载，其余页面不增加该预加载。

初始化最多等待 3 秒加载真实 Syne 700 FontFace。字体 API 缺失、失败或超时后，本次挂载保持 Logo；晚到的字体不会触发画面切换。断开组件会取消等待并使旧初始化代次失效，重连读取现有暂停状态。等待字体不累计动画活跃时间；首次绘制前手动暂停会冻结 SSR Logo，继续后才开始粒子入场。已绘制的画面与相位可在暂停、尺寸变化和重连后恢复。

粒子保留 700ms 停留与 1500ms 聚合，完成后持续在字形安全范围内流动。绘制预算为桌面入场及交互最多 60fps、桌面空闲最多 30fps、手机和平板全阶段最多 10fps。统一暂停按钮控制粒子与星球；自动星球凸显只暂停轨道，字内流动继续。离屏、后台和减少动态效果停止调度及活跃时间，恢复不补跑隐藏期间的动画。

## 几何根因与修复

浏览器在首次布局时曾将 motion-path 百分比中心依赖的参考盒按 0 缓存，导致星球轨道中心错误；单独固定首屏高度不能消除这个问题。修复使用独立的 orbit track，显式定义 `2 × rx`、`2 × ry` 尺寸，并以 rx／ry 长度定义路径中心，避免依赖首次布局的百分比参考盒。首屏舞台也有确定高度，使 SSR、无 JavaScript 和无 WebGL 状态下的轨道几何保持一致。

Canvas 使用 `actualBoundingBox` 测量字形墨迹，包括点号、下伸部和左右外伸，再按真实墨迹居中。可用宽度同时考虑椭圆在墨迹上下缘处的内缩、最大星球命中半径及描边缓冲；最多二分 12 次寻找不超过既有字号上限的合格尺寸。两站桌面、手机、平板和短屏均使用同一几何拟合，修复长开源字标在手机及扁平轨道上的碰撞。纯函数测试以独立的 72 角度圆形／矩形最近距离计算验证至少 16px 间距，而非重复实现公式。
