# 首屏轨道与双图标控制验证

本轮同步调整 weapp.dev 与 weapp.js.org：星球自动凸显、悬停和键盘聚焦时持续转动；右下角保留暂停／继续和重播两个纯图标按钮。证据目录为 `/tmp/weapp-hero-replay-20261011/`。

## 实现

两个控件均为 44×44px 点击区域、16px Lucide 图标，间隔 8px。各尺寸首屏均预留 64px 底部控制区，手机与平板轨道限制在其余舞台内，避免旋转到右下角时遮住控件。桌面和手机不显示按钮文字；中文／英文无障碍名称和原生 title 完整保留。暂停按钮同步 pressed、暂停／继续图标和名称。

轨道使用一个原生父层动画驱动继承的 `--orbit-turn`，星球、名称与选中亮弧共享相位。SVG 采用实际视口大小的椭圆和 `pathLength=100`，短亮弧以选中星球的等弧长进度为中心。没有持续布局读取或新增 RAF。自动凸显、悬停和键盘聚焦仅改变注意状态；用户暂停、离屏、后台、减少动画和入场阶段门禁控制轨道播放。

重播通过首屏作用域内持久版本通知各控制器，恢复粒子 Logo、清理说明和选中状态、重置粒子活跃时钟和轨道相位，解除用户暂停，复用已有字体和渲染资源。沿用 700ms 停留、1500ms 变形与 320ms 星球淡入；ready 后重新等待 3 秒，从首项目轮换。作用域彼此隔离，组件重连保留未重播的相位，并处理断开期间的新重播请求。隐藏状态重播先清理旧 framebuffer，避免旧字标叠在静态 Logo 下。

无 JavaScript 和减少动态效果时两个控件隐藏，静态粒子 Logo、背景和下方项目入口继续可用。字体失败／超时和 WebGL 失败维持原降级，不因重播重开字体期限或重复创建渲染器。未新增依赖或更改公共 props。

## 验证与发布

边界检查及 6 个边界测试通过。无缓存 lint、样式 lint、类型检查和单测共 16 个任务、215 个单元测试通过；最终 CSS 修改再次通过样式 lint，测试适配再次通过定向 ESLint。双站无缓存构建及必须产物、SEO 和内部链接验证通过。

定向真实浏览器回归 18 项通过、6 项按手机适用范围跳过，覆盖共享移动亮弧、完整组件重连及减少动画相位、字体等待中的重播、ready／partial／paused 重播、连续点击、后台旧 framebuffer 清除和作用域隔离。320px 手机与 844px 横屏的 8 个针对性布局测试全部通过。

双站 × 中英文 × 浅深主题 × 13 个尺寸，一轮截图及一轮修正确认共 208 张。尺寸涵盖 320／390px 手机、844×390 横屏、1024／1280／1440／1920px 桌面和 400／500／600px 短屏。完整 E2E 发现 320px 手机轨道会经过新增控制区，统一预留底部空间后修正；最终 104 张确认截图中，72 步轨道位置遍历、星球、名称、说明和两个控件的几何缺陷以及页面错误均为零。联系表和结果见 `qa-round2/`。

第一次截图尝试受到并行重建删除 dist 的影响而中断，没有计为完成的视觉轮次；其进程与任务浏览器已核对退出。正式截图批次只针对稳定产物执行，资源记录均为 `closed: true`，没有保留临时页面。

四段 1440×900 桌面／390×844 手机录屏和逐秒联系表确认：彩色星点 Logo 连续变成 Syne 字标，项目星球淡入，桌面凸显仍沿轨道移动；暂停后点击重播重新出现粒子 Logo，并正常完成字标和星球入场。证据见 `entry-video/`，页面错误为零；视频 browser、context、page 和临时 HTTP 服务器全部关闭。

两站依次以 desktop／mobile、2 个 worker 执行完整部署产物 E2E，全部为无头模式。
