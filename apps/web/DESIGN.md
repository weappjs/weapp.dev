# weapp.dev 设计约定

## 定位与共同语言

weapp.dev 是独立的商业 Astro 应用，面向需要小程序迁移、企业培训和模板定制的团队。采用根目录 [DESIGN.md](../../DESIGN.md) 的共同视觉语言：中性浅深表面、Geist 标题和正文、中文系统字体回退、宽裕章节、绿色主操作、胶囊控制与圆角真实媒体。此处不建立另一份 token 表；共享 token 的实际来源是 packages/site-ui/src/styles/foundation.css 和 classes.ts。

SSR 粒子 Logo 与星空、粒子字标和聚合后淡入的项目星球构成首屏标识，后续通过完整项目资料、真实演示和发布记录解释工具能力，再介绍服务与合作。主要媒体和浮层采用 20px 圆角；紧凑证据框与筛选器保留 12px。目录、详情、报价、赞助、隐私和 404 页面沿用同一层级与可访问性要求，不新增苹果资产或虚构商业证明。

## 页面与所有权

本应用拥有布局、导航、首页组合、双语文案、路由、SEO、隐私说明、本地交互和商业样式。首页依次呈现字标/星球与项目导航、定位与选型、工程、组件与数据、独立样式章节、Taro 迁移、Runtime 选型、uni-app 生态、工具链、真实发布、独立开源站介绍、当前服务、合作流程、规划、联系及自愿赞助。项目详情保留事实资料和同语种开源入口，并明确实施范围。

packages/project-catalog 只提供中立项目事实、资产与指标；packages/site-ui 只提供接收显式内容的中立视觉与演示组件。本应用不导入 apps/open-source，也不通过部署变量切换身份。只有本应用的 services.ts 决定商业服务覆盖，不能从项目目录或成熟度推导；价格、规划状态和基金规则不由设计层改写。

## 主题与交互

无有效保存值时默认深色；有效的 weapp-theme 浅色或深色选择优先，不自动跟随系统主题。首屏黑色舞台在两种主题中保持一致，行为遵循根目录 [首屏共享规范](../../DESIGN.md#particle-wordmark-and-project-planets)。SSR 首帧显示由小圆点组成的小程序 Logo 与固定种子的低亮度星空，品牌 H1 仅供辅助技术。等待真实 Syne 700 字体最多 3 秒，有效 WebGL 首帧才交接静态图层；随后 Logo 停留 700ms，再用 1500ms 变形成字标，字距 -0.02em。2200ms 进入 ready，后续 320ms 按活跃时间重叠淡入：轨道与星尘 0–180ms、星球 60–260ms、名称与说明 160–320ms；键盘聚焦星球始终可见，自动凸显从 ready 起等待 3 秒。字标完成后背景保持 6–12 秒错相闪烁，现有星数按固定种子分为近、远两层，分别以 45–75 秒和 90–150 秒周期缓慢漂移。宽度 ≥1024px 的精细鼠标指针仅驱动背景视差，远层径向上限 2px、近层 6px，约 250ms 活跃时间内收敛 95%；触屏、窄屏、链接与按钮不触发。暂停和重连保留当前位移，重播归零，SSR 与 WebGL 首帧位置、尺寸、亮度一致。星球使用固定左上高光、右下阴影和轻微项目色反射，独立不透明 Logo 面保留原色；选中时只放大星球内部视觉并强调球面描边与反射；轨道使用恒定冰白色 1px 核心与约 8px 柔和晕光（手机约 6px），核心与光环不随选择改变。入场、淡入和粒子共享活跃时钟与统一暂停，恢复不重播；桌面入场及交互最多 60fps、空闲最多 30fps，手机／平板全阶段最多 10fps。无 JavaScript、减少动画、字体失败或超时、WebGL 失败时保留静态粒子 Logo 与星空，轨道星球隐藏且 inert，下方项目入口仍可用。正文默认可见，短距离入场仅作增强。

轨道星尘由固定种子沿椭圆弧长等距锚定，法向抖动不超过 2px；宽度 ≥1024px／640–1023px／<640px 分别使用 960／384／256 个点。沿用既有翡翠、冰蓝、香槟与珍珠色，以珍珠色为主，各点按 6–12 秒错相周期独立闪烁，亮度变化限制在起点 ±25%，整圈不脉动。星尘复用现有 WebGL canvas、活跃时钟、ready 门禁、320ms 窗口内的 0–180ms 轨道淡入与 60／30／10fps 调度，统一暂停、重播与重连恢复相位；私有 program 和 VAO 随渲染器释放，测试探针分别统计两类资源。仅光环初始化失败时保留 CSS 核心与原粒子渲染器，其他静态降级约定不变。

共享主按钮与图标控制至少 44px，键盘焦点持续可见；中文与英文保持相同内容层级。既有联系方式、图表、复制、演示和静态导航仍由本应用负责验证。生产发布遵循本应用的 Cloudflare 检查和部署流程，见[维护手册](../../docs/maintenance.md)。
