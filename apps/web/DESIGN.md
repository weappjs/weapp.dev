# weapp.dev 设计约定

## 定位与共同语言

weapp.dev 是独立的商业 Astro 应用，面向需要小程序迁移、企业培训和模板定制的团队。采用根目录 [DESIGN.md](../../DESIGN.md) 的共同视觉语言：中性浅深表面、Geist 标题和正文、中文系统字体回退、宽裕章节、绿色主操作、胶囊控制与圆角真实媒体。此处不建立另一份 token 表；共享 token 的实际来源是 packages/site-ui/src/styles/foundation.css 和 classes.ts。

粒子字标与项目星球仍是首屏标识，后续通过完整项目资料、真实演示和发布记录解释工具能力，再介绍服务与合作。主要媒体和浮层采用 20px 圆角；紧凑证据框与筛选器保留 12px。目录、详情、报价、赞助、隐私和 404 页面沿用同一层级与可访问性要求，不新增苹果资产或虚构商业证明。

## 页面与所有权

本应用拥有布局、导航、首页组合、双语文案、路由、SEO、隐私说明、本地交互和商业样式。首页依次呈现字标/星球与项目导航、定位与选型、项目展示与演示、工具链、真实发布、独立开源站介绍、当前服务、合作流程、规划、联系及自愿赞助。项目详情保留事实资料和同语种开源入口，并明确实施范围。

packages/project-catalog 只提供中立项目事实、资产与指标；packages/site-ui 只提供接收显式内容的中立视觉与演示组件。本应用不导入 apps/open-source，也不通过部署变量切换身份。只有本应用的 services.ts 决定商业服务覆盖，不能从项目目录或成熟度推导；价格、规划状态和基金规则不由设计层改写。

## 主题与交互

无有效保存值时默认深色；有效的 weapp-theme 浅色或深色选择优先，不自动跟随系统主题。首屏黑色舞台在两种主题中保持一致。粒子停留 700ms、聚合 1500ms，之后最多 10fps，离屏与后台暂停；无 JavaScript 和减少动态效果保留静态字标。正文默认可见，短距离入场仅作增强。

共享主按钮与图标控制至少 44px，键盘焦点持续可见；中文与英文保持相同内容层级。既有联系方式、图表、复制、演示和静态导航仍由本应用负责验证。生产发布遵循本应用的 Cloudflare 检查和部署流程，见[维护手册](../../docs/maintenance.md)。

本轮验收记录见[设计验证记录](../../docs/apple-design-validation.md)。
