# weapp.js.org 设计约定

## 定位与共同语言

weapp.js.org 是独立的开源门户 Astro 应用，帮助开发者发现小程序项目、阅读文档、查看源码和参与贡献。采用根目录 [DESIGN.md](../../DESIGN.md) 的共同视觉语言：中性浅深表面、Geist 标题和正文、中文系统字体回退、大标题、宽裕章节、绿色主操作、胶囊控制和真实演示。此处不复制共享 token；实际来源是 packages/site-ui/src/styles/foundation.css 和 classes.ts。

SSR 粒子 Logo 与星空、粒子字标和聚合后淡入的项目星球保留独立站点识别。主要媒体、演示外框和浮层采用 20px 圆角，紧凑证据框与筛选器采用 12px。项目发现、文档链接、真实发布和贡献入口是主要展示内容；使用项目真实素材，不使用苹果私有资产或虚构社区证明。

## 页面与所有权

本应用拥有布局、导航、首页组合、双语文案、路由、SEO、隐私说明、本地交互和样式组合。首页依次呈现字标/星球与项目导航、定位与选型、工程、组件与数据、独立样式章节、Taro 迁移、Runtime 选型、uni-app 生态、工具链、发布和贡献入口。目录和详情保留十一个项目的真实维护者、文档、源码、成熟度及指标，weapp-sqlite 继续明确为规划中。

packages/project-catalog 提供中立事实、素材与指标，packages/site-ui 提供显式传入内容的中立视觉与演示组件。本应用不导入 apps/web，不以部署变量切换身份；共享外观不意味着共享商业定位。源码和发布资产不包含商业报价、募资、联系方式二维码或指向商业主域的服务导流。历史报价/赞助/贡献者资助 URL 保留同语种站内项目目录的 noindex 静态跳转。

## 主题与交互

无有效保存值时默认深色；有效的 weapp-theme 浅色或深色选择优先，不自动跟随系统主题。首屏黑色舞台在两种主题中保持一致，行为遵循根目录 [首屏共享规范](../../DESIGN.md#particle-wordmark-and-project-planets)。SSR 首帧显示由小圆点组成的小程序 Logo 与固定种子的低亮度星空，品牌 H1 仅供辅助技术。等待真实 Syne 700 字体最多 3 秒，有效 WebGL 首帧才交接静态图层；随后 Logo 停留 700ms，再用 1500ms 变形成字标，字距 -0.02em。2200ms 进入 ready，项目星球、名称与轨道在后续 320ms 内淡入，自动凸显从 ready 起等待 3 秒。字标完成后背景保持 6–12 秒错相闪烁与 45–75 秒缓慢漂移。星球使用固定左上高光、右下阴影和轻微项目色反射，独立不透明 Logo 面保留原色；选中时同时强调球面描边与当前位置的短轨道弧。入场、淡入和粒子共享活跃时钟与统一暂停，恢复不重播；桌面入场及交互最多 60fps、空闲最多 30fps，手机／平板全阶段最多 10fps。无 JavaScript、减少动画、字体失败或超时、WebGL 失败时保留静态粒子 Logo 与星空，轨道星球隐藏且 inert，下方项目入口仍可用。正文默认可见，短距离入场仅作增强。

共享主按钮与图标控制至少 44px；保留明显键盘焦点、静态导航、筛选与演示的默认内容、中英文等价层级。GitHub Pages 子路径与本站贡献链接由本应用独立验证。生产发布遵循本应用的检查、资产验证及 GitHub Pages 流程，见[维护手册](../../docs/maintenance.md)。
