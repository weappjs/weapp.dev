# Public project catalog

This private workspace package owns the nine public project definitions, their schemas and types, project logos/screenshots and their raw media-source captures, and the versioned GitHub/npm metrics snapshot. Existing project names, maintainers, repository URLs, documentation domains, and maturity remain authoritative.

Applications consume only the package exports. Do not import applications from this package or add service coverage, pricing, sponsorship, fund allocation, contact details, or site marketing copy here. Commercial service coverage belongs to apps/web; catalog membership never implies that service coverage.

Use pnpm metrics:sync from the repository root to refresh the snapshot. Ordinary site builds use the committed snapshot and make no live metrics requests. Asset generators in the open-source app write neutral project media here; application branding remains application-owned.
