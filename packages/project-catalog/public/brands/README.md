Panda CSS uses its selected P mark with the mini-program badge. StyleX uses its selected A1 orbit mark. See the upstream `assets/brand/README.md` for attribution and source material.

weapp-sqlite uses the transparent symbol from upstream commit `e1d370c7ef8a75185ca8c96dfd9abfca2a38f890` on the published `codex/redesign-sqlite-logo` branch, adopted on 2026-10-16. The two interlocking data blocks retain an S-shaped transparent channel. The [upstream brand guide](https://github.com/weapp-sqlite/weapp-sqlite/blob/e1d370c7ef8a75185ca8c96dfd9abfca2a38f890/assets/README.md) recommends at least 32px for navigation and project lists, and clear space of one eighth of the canvas width. Keep the proportions, colors, orientation, and transparent channel intact.
